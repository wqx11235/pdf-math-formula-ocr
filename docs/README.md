## 口径（先看这个，否则数字会对不上）

| 术语 | 定义 |
|---|---|
| **布局块** | SDK 版面检测出来的块，含正文、标题、表格、公式。吞吐常说的「块/分」默认指它 |
| **公式块** | 其中 `display_formula` / `inline_formula` 等，才进复核。约占布局块的 20~30% |
| **OK / CHECK** | Jev 分数 ≥ 阈值 / < 阈值 |
| **RENDER_FAIL** | 候选 LaTeX 用 xelatex 编不出 PDF（不是「错」，是「不可用」） |
| **SCORE_ERR** | 打分服务失败（含重试后仍失败）；**未打分 ≠ 错** |
| **人工必看** | CHECK + RENDER_FAIL + SCORE_ERR 三项之和 |

两套数据不要混着比：

- **3,382 块**：4 本书全量（2026-11-20），用来算人工成本与判定分布。
- **859 块 / 199 页**：34 本抽样（2026-11-24），用来做并发参数对比与吞吐基准。
